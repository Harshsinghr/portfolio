# Harsh Singh — Portfolio

Personal portfolio of Harsh Singh, an AI engineer based in Kanpur, India.

**Live site:** https://harshsinghr.github.io/portfolio/

## About the site

A single-page, dark-themed portfolio covering experience, achievements and writing.
Built with plain HTML, CSS and JavaScript. There is no build step and no dependencies.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 4173
```

Then visit http://localhost:4173.

## Project structure

```
index.html        page content
css/styles.css    design tokens, layout and components
js/main.js        scroll-spy, reveal animations and small interactions
assets/           favicon
```

## Deployment

Hosted on GitHub Pages from the `main` branch, root folder.
